# معرض أعمال محمد عبد العزيز محمد

موقع portfolio ثابت باللغة العربية، مبني بـ HTML وCSS وJavaScript فقط. لا يحتاج إلى خادم أو اشتراك، ويمكن استضافته مجانًا على GitHub Pages أو Netlify أو Cloudflare Pages.

## قبل النشر

1. راجع الاسم والوصف التعريفي في `index.html` وتأكد من ملاءمتهما لك.
2. قسم الأعمال يعرض ثلاث صور تجريبية مؤقتة في `assets/placeholders/` للمعاينة فقط؛ لا تمثل أعمالًا منفذة أو مشاريع عملاء. استبدل الصور والعناوين والأوصاف بأعمالك الفعلية قبل النشر.
3. أضف روابط حساباتك الاجتماعية عند توفرها.

## نشر مجاني

ارفع محتويات هذا المجلد إلى مستودع GitHub عام، ثم افتح **Settings → Pages** واختر **Deploy from a branch** والفرع `main` والمجلد `/ (root)`. سيكون الموقع متاحًا على عنوان GitHub Pages المجاني. كما يمكن ربط المجلد بمشروع جديد على Netlify أو Cloudflare Pages دون build command.

## الملفات

- `index.html` — بنية الصفحة ومحتواها.
- `styles.css` — الهوية البصرية والتنسيق المتجاوب.
- `script.js` — تحديث سنة حقوق النشر تلقائيًا.
- `favicon.svg` — أيقونة الموقع.
- `assets/placeholders/` — صور مؤقتة مولّدة بصريًا، استبدلها بأعمالك قبل النشر.

الخطوط تُحمّل من Google Fonts؛ إذا أردت استضافة ذاتية بالكامل، نزّل الخطوط وأشر إليها محليًا في CSS.
